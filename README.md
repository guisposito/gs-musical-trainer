# 🎸 Guitar String Trainer

WebApp educacional para treino de guitarra com detecção de pitch em tempo real.

## 🚀 Quick Start

```bash
# Instalar dependências
npm install

# Rodar em desenvolvimento
npm run dev

# Acesse http://localhost:3000
```

## ✨ Funcionalidades

- ✅ Detecção de pitch em tempo real (Web Audio API)
- ✅ Sorteio aleatório de notas + cordas
- ✅ Validação automática com feedback visual
- ✅ Interface moderna e responsiva
- ✅ 78 posições do braço (6 cordas × 13 casas)
- ✅ Performance otimizada (60 FPS, <100ms latência)

## 🛠️ Tech Stack

- **Next.js 14** - Framework React
- **TypeScript** - Type safety
- **TailwindCSS** - Styling
- **Web Audio API** - Pitch detection
