# ⚡ Quick Start - Guitar String Trainer

Comece a usar em **3 minutos**!

## 🚀 Instalação Rápida

```bash
# 1. Navegue até a pasta do projeto
cd "GS musical trainer"

# 2. Instale dependências
npm install

# 3. Inicie o servidor
npm run dev
```

## 🎮 Primeiro Uso

1. Abra o navegador em: **http://localhost:3000**
2. Clique em **"🎸 Iniciar Treino"**
3. Permita acesso ao **microfone**
4. Toque a nota mostrada na tela
5. ✅ **Verde** = Acertou! ❌ **Vermelho** = Tente novamente

## 🎸 Dicas Rápidas

- Toque notas **sustentadas** (longas)
- **Afine** sua guitarra antes
- Volume **médio-alto** funciona melhor
- Use **fones** para evitar feedback

## 🆘 Problemas?

**Microfone não funciona?**
- Verifique permissões do navegador (ícone de cadeado)

**Não detecta notas?**
- Aumente o volume da guitarra
- Toque mais perto do microfone

**Detecção errada?**
- Afine sua guitarra
- Reduza ruído ambiente
